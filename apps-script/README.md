# 익명 댓글 · Apps Script 적용 방법

용어 상세 화면 맨 아래의 익명 댓글이 동작하려면, 지금 쓰는 Apps Script 웹 앱(`index.html`의 `NEWBIKEY_API`)에 `comments.gs`를 추가해야 해요.
**이 작업 전에는 앱의 댓글 영역에 "댓글을 불러오지 못했어요"가 보이고, 나머지 기능은 그대로 동작해요.**

## 1. 파일 추가 (기존 코드는 지우지 않아요)

1. 「뉴비키 등록 요청」 시트 → 확장 프로그램 → Apps Script를 열어요. (용어 불러오기·요청하기에 쓰는 그 프로젝트)
2. 왼쪽 「파일」 옆 **+ → 스크립트**를 누르고, 이름을 `comments`로 해요.
3. 저장소의 `apps-script/comments.gs` 내용을 **전부 복사해서 붙여 넣고** 저장해요.

## 2. 기존 doGet / doPost에 한 줄씩 추가

기존 코드에서 `function doGet(e) {`와 `function doPost(e) {`를 찾아, **여는 중괄호 바로 다음 줄**에 아래를 넣어요.

```js
function doGet(e) {
  var cmtRes = handleCommentsGet_(e); if (cmtRes) return cmtRes;   // ← 이 줄 추가
  // ... 기존 코드 그대로 ...
}

function doPost(e) {
  var cmtRes = handleCommentPost_(e); if (cmtRes) return cmtRes;   // ← 이 줄 추가
  // ... 기존 코드 그대로 ...
}
```

댓글이 아닌 요청(용어 불러오기, 요청하기, 나도 궁금해요)이면 이 줄은 아무 일도 하지 않고 기존 코드로 넘어가요.

## 3. 설정 확인 (comments.gs 맨 위)

- `CMT_BOOK_ID`: 비워 두면 스크립트가 붙어 있는 시트(「뉴비키 등록 요청」)에 「댓글」·「좋아요」 탭을 만들어요.
  스크립트가 시트에 붙어 있지 않은 독립 프로젝트라면 「뉴비키 등록 요청」 주소의 `/d/`와 `/edit` 사이 ID를 넣어 주세요.
- `CMT_TERM_BOOK_ID` (선택): 「뉴비키 용어집」 시트 ID를 넣으면, 용어집에 실제로 있는 id에만 댓글을 받아요. 비워 두면 id 형식만 검사해요.

## 4. 배포 — 꼭 "새 버전"으로

1. 오른쪽 위 **배포 → 배포 관리**
2. 지금 쓰는 배포를 고르고 **연필(수정)** 아이콘
3. 버전: **새 버전** → **배포**

⚠️ **「새 배포」를 누르면 주소가 바뀌어서 앱 전체(용어 불러오기 포함)가 구글 시트를 못 읽게 돼요.** 반드시 기존 배포를 수정하세요.
처음 실행할 때 권한 확인 창이 뜨면 허용해 주세요.

## 5. 확인

1. 브라우저에서 `NEWBIKEY_API` 주소 뒤에 `?only=comments&term=pbc`를 붙여 열어요 → `{"ok":true,"comments":[]}`가 보이면 성공
2. 앱에서 아무 용어 상세 화면 → 댓글 작성 → 시트에 「댓글」 탭이 생기고 한 줄 추가됐는지 확인
3. 기존 기능(용어 목록, 요청하기)도 그대로인지 확인

## 운영

- **댓글 내리기:** 「댓글」 탭에서 그 행의 「숨김」 체크박스를 체크 → 앱을 새로고침하면 사라져요. (행을 지우지 않아도 돼요)
- **좋아요:** 「좋아요」 탭에 (댓글ID, 브라우저ID) 한 줄씩 쌓여요. 수는 이 탭을 세서 보여줘요.
- 시트를 편집할 수 있는 사람은 댓글을 숨기거나 고칠 수 있으니 공유 범위를 운영진으로 제한해 주세요.

## 동작 원리 (참고)

- 익명 번호: 스크립트 잠금(`LockService`)을 건 상태에서 그 용어의 가장 큰 번호 + 1을 저장 → 동시에 써도 번호가 겹치지 않아요. 용어마다 1부터 시작해요.
- 좋아요 1번: 같은 잠금 안에서 (댓글ID, 브라우저ID)가 이미 있으면 추가하지 않아요. 브라우저ID는 앱이 만든 무작위 값으로, 중복 방지에만 써요.
- 내용 검사: 앞뒤 공백 제거 후 1~500자. `=`, `+`, `-`, `@`로 시작하는 글은 시트가 수식으로 읽지 않게 글자로 저장해요.

## 알려진 제약

- Apps Script 특성상 댓글 작성·좋아요 응답에 1~3초 걸려요.
- 동시에 매우 많은 사람이 쓰면(수십 명 이상 동시) 잠금 대기 10초를 넘겨 "잠시 후 다시 시도" 안내가 나올 수 있어요.
- 사용자 스스로 삭제·수정·신고하는 기능은 없어요 (운영진이 숨김으로 관리).
- 브라우저 데이터를 지우거나 다른 브라우저를 쓰면 같은 댓글에 좋아요를 다시 누를 수 있어요.
