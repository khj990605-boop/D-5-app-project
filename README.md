# 뉴비키

신입 회계사가 회계법인에서 쓰는 은어·용어를 쉽게 찾아볼 수 있는 웹앱이에요. (2026 DISCOVER D-5조)

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 (디자인 · 검색 · 화면 이동) |
| `data.js` | 용어 데이터. **엑셀에서 자동으로 만들어지니 직접 고치지 않아요** |
| `data/회계법인_용어집.xlsx` | 용어집 원본. 용어를 추가하거나 고칠 때는 이 파일을 고쳐요 |
| `scripts/build_data.py` | 엑셀을 `data.js`로 바꾸는 스크립트 |

## 화면 확인

`index.html`을 더블클릭해서 브라우저로 열면 돼요. `data.js`는 같은 폴더에 있어야 해요.

## 용어를 고치거나 추가할 때

1. `data/회계법인_용어집.xlsx`의 「용어집」 시트를 고쳐요.
   - A~G열: 용어명, 정의, 사용 예시, 관련 용어·키워드, 최종 수정일, 등록자, 출처
   - H~N열(웹앱용): id, 표시 이름, 별칭, 카테고리, 난이도, 검수 상태, 많이 찾은 말 순위
2. 저장소 폴더에서 아래 명령을 실행해요.
   ```
   pip install openpyxl
   python scripts/build_data.py
   ```
3. `완료: data.js (용어 N개 …)`가 나오면 성공이에요. 엑셀에 잘못된 값이 있으면 몇 번째 행을 고쳐야 하는지 알려줘요.
4. GitHub Desktop에서 바뀐 파일(엑셀, `data.js`)을 커밋하고 Push해요.

### 엑셀 작성 규칙

- **id**: 영어 소문자와 숫자만 써요 (예: `geumjo`). 주소(`#term-geumjo`)에 쓰여서 한 번 정하면 바꾸지 않는 게 좋아요.
- **별칭**: 검색에 걸리는 다른 이름이에요. 쉼표로 구분해요 (예: `PBC, Provided by Client`).
- **카테고리**: 목록에서 골라요. 카테고리 이름·색·설명은 「카테고리」 시트에서 관리해요.
- **난이도**: 입사 첫 주 / 한 달 안에 / 알아두면 좋아요
- **검수 상태**: 검수 완료 / 검토 중 / 수정 필요
- **사용 예시**: 문장을 `“ ”`로 감싸고 ` / `로 구분하면 예시가 여러 개로 나뉘어 보여요.
- **관련 용어 및 연관 키워드**: 쉼표로 구분해요. 용어집에 있는 단어는 「같이 알아두면 좋은 말」 버튼으로, 없는 단어는 `#키워드`로 보여요.
- **많이 찾은 말 순위**: 홈에 1·2·3위로 보여줄 용어에만 숫자를 적어요.
