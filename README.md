# 뉴비키

신입 회계사가 회계법인에서 쓰는 은어·용어를 쉽게 찾아볼 수 있는 웹앱이에요. (2026 DISCOVER D-5조)

## 용어가 앱에 들어가는 길 (2026.10.05 바뀜)

용어 원본은 이제 **팀 공유 드라이브의 「뉴비키 용어집」 구글 시트**예요.
앱은 열릴 때마다 이 시트를 읽어 오기 때문에, **시트를 고치고 앱을 새로고침하면 바로 반영돼요.** GitHub에 올릴 필요가 없어요.

```
「뉴비키 용어집」 구글 시트 ──(앱이 열릴 때 읽음)──▶ 뉴비키 앱
                                  ▲
「뉴비키 등록 요청」 구글 시트의 Apps Script 웹 앱이 중간에서 읽어서 보내 줘요
```

- **고칠 곳 확인**: 웹 앱 주소 뒤에 `?check=1`을 붙여 브라우저로 열면, 잘못 입력해서 앱에 안 보이는 행이 몇 번째인지 알려줘요.
  잘못된 행(id 규칙 위반, id 중복, 없는 카테고리)은 앱에 보내지 않고 건너뛰어요. 나머지 용어는 그대로 보여요.
- **편집 권한 = 게시 권한**: 용어집 시트를 편집할 수 있는 사람은 누구나 앱 내용을 바로 바꿀 수 있어요. 편집 권한은 필요한 사람에게만 주세요.
- **구글에 연결이 안 될 때**: 앱은 그 브라우저가 마지막으로 읽은 시트 내용을, 그것도 없으면 `data.js`(비상용)를 보여줘요.
- **선택 열**: 「용어집」 시트 1행에 `쉽게 말하면`, `선배 팁`, `검수자` 머리글을 추가하면 상세 화면에 함께 보여요. (검수자는 검수 상태가 「검수 완료」일 때만 보여요)

## 등록 요청이 쌓이는 곳

앱에서 「요청하기」·「나도 궁금해요」를 누르면 **「뉴비키 등록 요청」 구글 시트의 「요청」 탭**에 한 줄씩 쌓여요. 이름은 저장하지 않아요.

- 처리 상태: `대기` → 용어집에 넣었으면 `등록 완료`, 장난 요청이면 `제외`(앱의 요청 수에서 빠져요)
- 같은 시트의 Apps Script가 요청 받기와 용어 보내기를 함께 해요. 웹 앱은 **배포한 사람의 계정 권한**으로 돌아가요.
- Apps Script 코드를 고치면 [배포] → [배포 관리] → ✏️ → 버전 「새 버전」 → [배포]. 이렇게 하면 주소가 그대로예요.
  「새 배포」를 하면 주소가 바뀌니, 그때는 `index.html`의 `NEWBIKEY_API`도 바꿔야 해요.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 (디자인 · 검색 · 화면 이동) |
| `data.js` | **비상용** 용어 데이터. 구글 시트를 읽지 못할 때만 써요. 엑셀에서 자동으로 만들어지니 직접 고치지 않아요 |
| `data/회계법인_용어집.xlsx` | 예전 원본(2026.10.05까지). 지금 원본은 구글 시트예요. 비상용 `data.js`를 새로 만들 때만 써요 |
| `scripts/build_data.py` | 엑셀을 `data.js`로 바꾸는 스크립트 |

## 화면 확인

`index.html`을 더블클릭해서 브라우저로 열면 돼요. `data.js`는 같은 폴더에 있어야 해요.

## (가끔) 비상용 data.js 새로 만들기

구글 시트 내용을 비상용으로도 남겨 두고 싶을 때만 해요. 구글 시트에서 [파일] → [다운로드] → [Microsoft Excel]로 받아 `data/회계법인_용어집.xlsx`를 덮어쓴 뒤 아래 순서를 따라요.

### 엑셀에서 data.js 만들기

1. `data/회계법인_용어집.xlsx`의 「용어집」 시트를 고쳐요.
   - A~G열: 용어명, 정의, 사용 예시, 관련 용어·키워드, 최종 수정일, 등록자, 출처
   - H~N열(웹앱용): id, 표시 이름, 별칭, 카테고리, 난이도, 검수 상태, 많이 찾은 말 순위
2. 저장소 폴더에서 아래 명령을 실행해요.
   ```
   pip install openpyxl
   python scripts/build_data.py
   ```
3. `완료: data.js (용어 N개 …)`가 나오면 성공이에요. 엑셀에 잘못된 값이 있으면 몇 번째 행을 고쳐야 하는지 알려줘요.
4. GitHub Desktop에서 바뀐 파일(엑셀, `data.js`)을 커밋하고 Push해요.

### 엑셀 작성 규칙

- **id**: 영어 소문자와 숫자만 써요 (예: `geumjo`). 주소(`#term-geumjo`)에 쓰여서 한 번 정하면 바꾸지 않는 게 좋아요.
- **별칭**: 검색에 걸리는 다른 이름이에요. 쉼표로 구분해요 (예: `PBC, Provided by Client`).
- **카테고리**: 목록에서 골라요. 카테고리 이름·색·설명은 「카테고리」 시트에서 관리해요.
- **난이도**: 입사 첫 주 / 한 달 안에 / 알아두면 좋아요
- **검수 상태**: 검수 완료 / 검토 중 / 수정 필요
- **사용 예시**: 문장을 `“ ”`로 감싸고 ` / `로 구분하면 예시가 여러 개로 나뉘어 보여요.
- **관련 용어 및 연관 키워드**: 쉼표로 구분해요. 용어집에 있는 단어는 「같이 알아두면 좋은 말」 버튼으로, 없는 단어는 `#키워드`로 보여요.
- **많이 찾은 말 순위**: 홈에 1·2·3위로 보여줄 용어에만 숫자를 적어요.
